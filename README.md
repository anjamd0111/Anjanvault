Anjan Digital Vault
A lightweight, self-hosted file vault. Visitors upload files from a clean public page; only the admin can view, play, download or delete them. Built with Node.js and Express, with no database required.
Features
Public upload page: drag and drop or tap to select, multiple files at once, live progress bar
Private storage: uploaded files are visible only to the admin
Admin panel: play audio and video, preview images, download or delete files
Visitor analytics: total and unique visits, daily chart, device breakdown, plus per-visit details (device, browser, IP, approximate location, battery, network)
Customisation: colour themes, background photo, darkness and blur controls, all from the Settings tab
Responsive: designed mobile-first
Tech stack
Node.js and Express
Multer for uploads
Plain HTML, CSS and JavaScript on the front end (single file, no build step)
JSON files on disk for metadata, settings and visit logs
Getting started
Requirements: Node.js 18 or newer.
